# blockaimbot

Minecraft Java **26.2**, Fabric, Java 25용 클라이언트 모드입니다.

## 사용

1. Fabric Loader 0.19.3 이상, 26.2용 Fabric API와 이 모드를 `mods` 폴더에 넣습니다.
2. 설정 화면을 모드 목록에서 열려면 26.2용 **Mod Menu 20.x**도 설치합니다. Mod Menu는 선택 의존성입니다.
3. 원하는 블록을 바라보고 `/block`을 입력합니다. 특정 좌표가 아니라 **블록 종류**를 등록합니다. 예: 다이아몬드 광석.
4. 기본 **r 키를 누르고 있는 동안**, 최대 거리 안에 있는 같은 종류 중 가장 가까운 보이는 블록으로 조준합니다. 키를 놓으면 즉시 해제합니다.
5. 모드 목록 → blockaimbot → 설정에서 조준 속도, 최대 거리, 속도 랜덤화를 변경합니다. 키는 설정 화면의 키 변경 버튼 또는 게임 설정 → 조작 → 키 설정에서 변경합니다.

`/block clear`: 대상 해제. `/block settings`: Mod Menu 없이 설정 화면 열기.

## 설정

| 항목 | 범위 | 기본값 |
| --- | --- | --- |
| 조준 속도 | 5–720도/초 | 180도/초 |
| 최대 거리 | 1–16블록 | 6블록 |
| 속도 랜덤화 | ±0–50% | 0% |

랜덤화는 대상을 새로 잡을 때 조준 속도 배율을 한 번 선택합니다. 예: 180도/초, ±10%이면 162–198도/초입니다. 매 틱 에임을 흔드는 방식이 아닙니다. **안티매크로·안티치트 우회 성공을 보장하지 않으며 우회 검증도 수행하지 않았습니다.**

설정은 `config/blockaimbot.json`, 키 설정은 Minecraft의 `options.txt`에 저장됩니다. 슬라이더를 변경할 때 바로 저장하며 esc로 닫아도 저장합니다. 대상 종류는 재접속 후에도 유지됩니다. 화면을 열거나 창이 비활성화되면 조준을 해제합니다.

## 탐색 기준과 제한

- 플레이어 눈 위치에서 블록 **중심까지 거리**로 최대 거리와 가장 가까운 대상을 판단합니다.
- 로드된 청크만 검사합니다. 블록 outline shape 중심점으로 레이캐스트해 벽에 가려진 대상은 제외합니다. 일부만 보이는 복잡한 모양은 탐색에서 제외될 수 있습니다.
- 대상 탐색은 보통 초당 5회, 현재 대상이 사라지거나 가려지면 즉시 다시 탐색합니다. 반경 상한은 16블록입니다.
- 자동 채굴·클릭 기능은 없습니다. 조준 거리는 서버의 채굴·상호작용 거리를 늘리지 않습니다.
- 명령은 클라이언트에서 처리합니다. 서버에도 `/block` 명령이 있으면 같은 이름과 충돌할 수 있습니다.

## 개발 및 빌드

Java 25로:

```sh
./gradlew clean build
```

Windows:

```powershell
.\gradlew.bat clean build
```

출력: `build/libs/blockaimbot-1.0.0.jar`. `-sources.jar`는 설치용이 아닙니다.

검증 상태는 작업 완료 보고 및 GitHub Actions 실행 결과를 확인하세요. 소스 작성만으로 실제 게임 실행이나 서버 감지 여부를 검증한 것은 아닙니다.
