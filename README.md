# blockaimbot

Minecraft Java **1.21.11**, Fabric, Java 21용 클라이언트 모드입니다.

26.2용은 [`main`](https://github.com/MaJeong3124/blockaimbot/tree/main), 1.21.11용은 [`1.21.11`](https://github.com/MaJeong3124/blockaimbot/tree/1.21.11) 브랜치입니다. 버전별 jar를 맞춰 설치하세요.

## 사용

1. Fabric Loader 0.19.3 이상, 1.21.11용 Fabric API와 이 모드를 `mods` 폴더에 넣습니다.
2. 설정 화면을 모드 목록에서 열려면 1.21.11용 **Mod Menu 17.x**도 설치합니다. Mod Menu는 선택 의존성입니다.
3. 원하는 블록을 바라보고 `/block`을 입력합니다. 특정 좌표가 아니라 **블록 종류**를 등록합니다. 예: 다이아몬드 광석.
4. 기본 **r 키를 누르고 있는 동안**, 최대 거리 안에 있는 같은 종류 중 가장 가까운 보이는 블록으로 조준합니다. 키를 놓으면 즉시 해제합니다.
5. 모드 목록 → blockaimbot → 설정에서 조준 속도, 최대 거리, 움직임 랜덤화를 변경합니다. 키는 설정 화면의 키 변경 버튼 또는 게임 설정 → 조작 → 키 설정에서 변경합니다.

`/block clear`: 대상 해제. `/block settings`: Mod Menu 없이 설정 화면 열기.

## 설정

| 항목 | 범위 | 기본값 |
| --- | --- | --- |
| 조준 속도 | 5–720도/초 | 180도/초 |
| 최대 거리 | 1–16블록 | 6블록 |
| 움직임 랜덤화 | 0–50% | 15% (새 설정) |

랜덤화는 같은 대상으로 이동하는 동안에도 속도 배율과 작은 방향 편차를 0.3–0.6초 간격으로 부드럽게 바꿉니다. 직선 대신 완만한 곡선과 미세한 흔들림을 만들며, 출발과 목표 접근 시 속도를 낮춥니다. 목표 근처에서는 편차를 줄이고 최종 조준이 끝나면 흔들림을 멈춥니다. 수치는 속도 변화·곡선·흔들림을 함께 조절하며 0%는 기존 직선 이동입니다. 새 설정의 기본값은 15%, 기존 설정 파일의 0%는 그대로 유지되므로 기존 사용자는 설정에서 10–20%로 올려 시험할 수 있습니다. 사람의 움직임을 측정·재현한 모델은 아닙니다. **안티매크로·안티치트 우회 성공을 보장하지 않으며 우회 검증도 수행하지 않았습니다.**

설정은 `config/blockaimbot.json`, 키 설정은 Minecraft의 `options.txt`에 저장됩니다. 슬라이더를 변경할 때 바로 저장하며 esc로 닫아도 저장합니다. 대상 종류는 재접속 후에도 유지됩니다. 화면을 열거나 창이 비활성화되면 조준을 해제합니다.

## 탐색 기준과 제한

- 플레이어 눈 위치에서 블록 **중심까지 거리**로 최대 거리와 가장 가까운 대상을 판단합니다.
- 로드된 청크만 검사합니다. 블록 outline shape 중심점으로 레이캐스트해 벽에 가려진 대상은 제외합니다. 일부만 보이는 복잡한 모양은 탐색에서 제외될 수 있습니다.
- 대상 탐색은 보통 초당 5회, 현재 대상이 사라지거나 가려지면 즉시 다시 탐색합니다. 반경 상한은 16블록입니다.
- 자동 채굴·클릭 기능은 없습니다. 조준 거리는 서버의 채굴·상호작용 거리를 늘리지 않습니다.
- 명령은 클라이언트에서 처리합니다. 서버에도 `/block` 명령이 있으면 같은 이름과 충돌할 수 있습니다.

## 개발 및 빌드

Java 21로:

```sh
./gradlew clean build
```

Windows:

```powershell
.\gradlew.bat clean build
```

출력: `build/libs/blockaimbot-1.1.0+mc1.21.11.jar`. `-sources.jar`는 설치용이 아닙니다.

검증 상태는 작업 완료 보고 및 GitHub Actions 실행 결과를 확인하세요. 소스 작성만으로 실제 게임 실행이나 서버 감지 여부를 검증한 것은 아닙니다.

공식 참고: [1.21.11 개발 변경](https://fabricmc.net/2025/12/05/12111.html), [1.21.11 설정 화면](https://docs.fabricmc.net/1.21.11/develop/rendering/gui/custom-screens).
